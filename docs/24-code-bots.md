# 制限付きコード Bot

## 利用方法

リーグでコード Bot を選択し、サンプルを読み込んで編集・登録します。[サンプル](../examples/decision_bot.py)は未充足量を考慮する戦略であり、他の戦略に必ず勝つものではありません。登録したコードは保存され、次の時間帯から使われます。変更は新規登録となり、順位ポイントは 1000 から始まります。

## 入出力

`def decide(request):` 一つだけを定義します。`request` は `turn`、`total_turns`、`observation` を含みます。観測は倉庫、車両、道路、避難所と発生済みイベントで、未来のイベント計画は含みません。

戻り値は `{'protocol_version': '0.1', 'turn': request['turn'], 'actions': [...]}`。配車行動には `vehicle_id`、`type: 'dispatch'`、`target_shelter_id`、正の整数 `quantity` が必要です。在庫・容量・状態・重複配車等はエンジンが検証します。

## 利用できる構文

- ローカル変数、リスト、文字列キーの辞書、添字による読み取り。
- リストに対する `for`、`if/else`、`break`、`continue`、`return`。
- 有限数の `+ - * / // %`、スカラー比較、`and/or/not`、条件式。
- `len`、数値に対する `min` / `max` / `abs`。
- `append(items, item)` は新しいリストを返します。`actions = append(actions, action)` と書き、`.append` は使いません。

属性アクセス、import、ファイル、ネットワーク、eval/exec、クラス、再帰、補助関数、while、内包表記、第三者ライブラリは使えません。AST を許可した演算だけで解釈し、ユーザー Python バイトコードを実行しません。**完全な Python 環境や汎用 Python サンドボックスではありません。**

## 上限とエラー

ソース 6000 UTF-8 バイト、AST 1500 ノード、1 ターン 12000 ステップまで。リスト走査は 256 項、append のリスト長は 128 項までです。数値は有限で絶対値 1e12 以下、出力の深さは 16 以下です。出力走査もステップ数に含みます。

ターンごとにスコープを作り直し、可変状態を持ち越しません。構文エラーは登録時に拒否します。実行エラーや上限超過は `bot_error` として記録し、そのターンは配車しません。移動中の車両の輸送は続きます。診断は英語の技術詳細を含む場合があります。

リプレイには言語バージョンとソース SHA-256 を含みますが、ソース本体や管理トークンは公開しません。逐行デバッガーや外部 HTTP Bot は未提供です。

## 検証

既存テストは実行、再現性、行動検証、保存後の参加、禁止構文、数値・ステップ・出力上限を確認します。今回の実行結果とモバイル確認は[受入記録](18-mvp-acceptance.md)を参照してください。実クラウドでの候補版検証は次段階です。
