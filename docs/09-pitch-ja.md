# ReliefRoute Arena — 紹介

ReliefRoute Arena は、災害時の救援物資の配送を題材に、自分の戦略を同じ条件で比較できるシミュレーションプラットフォームです。Hachimitsu が医療・福祉分野の学習支援として取り組んでいます。

利用者は配送先の優先順位、積載量、出発条件を選び、模擬試合を実行します。全体の配送量だけでなく、期限、公平性、資源効率を見ながら地図リプレイで結果を振り返ります。時間別リーグには、設定式の Bot と制限付きコード Bot が参加できます。

判断と採点は決定的な Python で行い、経路には Dijkstra 型の最短経路計算を使います。LLM は採点や Bot の意思決定に使いません。Cloud Run でオンライン実行し、Cloud Storage・Jobs・Scheduler を組み合わせて保存と定期対戦を行う構成です。候補版のクラウド最終検証は次段階です。

完全に架空の教育・戦略研究用環境であり、実際の救援指揮を行うものではありません。九つの地図は視覚レイアウト、完全なリプレイは最新ラウンドのみという制約を明示します。利用者の学習効果は今後検証します。
