# 可视化前端与本地 API（v0.3）

## 启动

在仓库根目录执行 `python3 -m reliefroute.server`，打开 `http://127.0.0.1:8000`。可用 `--port 8002` 更换端口；Ctrl+C 停止。Python 3.9+，只使用标准库。

浏览器需要支持 JavaScript modules、SVG 和现代 CSS。没有安装/构建步骤，也没有依赖 CDN、字体服务或真实地图。建议使用现代 Chrome/Safari/Edge。

## 使用流程

1. 默认加载事件场景 seed 11 的最近优先结果，停在回合 0。
2. 选择场景、seed 和策略，点击“运行比赛”。计算完成后开始播放；窄屏自动滚动到路网。
3. 使用暂停、单步、回到开始、回放速度、时间轴定位任意回合。
4. 查看当回合道路颜色及文字、车辆位置/目标/载货、需求满足量和已经发生的事件。点击节点或避难所卡片突出所选避难所。
5. 右侧成绩是整场结束后的总分与分项，不随时间轴变化；需求卡片与事件日志随时间轴变化。
6. 切换“策略对照”，运行最近/紧急度优先在公开 seed 11/22/33 的六场比赛；点击“查看”回到对应比赛。
7. 点击“下载比赛记录”，导出完整 JSON；可执行 `python3 -m reliefroute --rescore <下载文件路径>` 重算成绩。

更改配置后需要点击运行，现有地图标题继续显示正在查看的比赛 seed/Bot。计算失败时显示错误并允许重试，不伪造新结果。

## 回放语义

- 每一帧是 `log[turn].state`，包含本回合事件、移动、卸货和派遣完成后的状态。
- 在道路中的车辆按该次路段进入时锁定的耗时与剩余回合定位；回放是离散状态展示，不代表真实 GPS。
- SVG 的 N0/N1/N2/N3 坐标仅用于视觉布局，不改变道路权重。
- 道路显示关闭优先于拥堵；道路开放且耗时高于初始值时显示拥堵。当前受控场景初始均无拥堵，未来若支持初始拥堵须扩展显示契约。
- 事件列表最多展示至当前回合；不会提前显示未来道路事件或需求。页面是开发者回放工具，不是 Bot 的观察接口。

## 本地接口

| 路径 | 参数 | 输出 |
| --- | --- | --- |
| GET `/api/match` | scenario=events/fixture；seed=32 位整数；bot=nearest/urgency | 完整比赛日志、summary、score、bot |
| GET `/api/compare` | 无 | 三个 seed、六场摘要/成绩及均分排名 |
| GET `/`、`/app.js`、`/style.css` | 无 | 白名单静态资源 |

默认事件 seed 11、Bot nearest；基础夹具仅接受 seed 0。未知场景/Bot/参数、重复参数及非法 seed 返回 400；其他文件路径返回 404。仅监听 `127.0.0.1`，不支持任意 Bot URL、上传文件、数据库或身份认证。

## 文件与后续工作

- `web/`：中文界面、响应式布局、SVG 路网、回放/对照逻辑。
- `reliefroute/server.py`：本机开发服务与引擎适配。
- `tests/test_server.py`：真实 HTTP 集成回归。

下一阶段仍需无代码 Bot 配置、生产 API、云部署与公开演示验收。本地前端没有改变已冻结的开发评分基线。


## 三语界面（v0.3.1）

顶部菜单提供中文、日本語、English。第四轮起，无已保存偏好时固定默认日本語（不随浏览器语言变化）；将选择保存到浏览器同源的 localStorage（键 `reliefroute.language`）。刷新会保留语言；浏览器禁止存储时仍支持当前页面内切换。不同端口/域名的语言设置相互独立。

切换即时更新静态标签、页面标题、`html.lang`、无障碍说明、动态事件/车辆/需求/计分和对照表。保持当前 seed、Bot、视图、回合、播放/暂停状态与已计算结果；不因切换语言发起新的比赛请求。导出的 JSON 维持语言无关的原始字段与分数，CLI 行为不变。

`web/i18n.js` 集中管理三语词条及参数插值；静态节点通过 `data-i18n` 和属性标记绑定，动态界面使用 `t()`。更新词条时须同时维护三种语言的键与参数占位符。英文计数为 1 时使用单数词条。产品名称、Bot/场景版本、C/T/F/E 指标代码与 ID 保持原样。

添加 `tests/test_i18n.py` 检查词条一致性、占位符、HTML/动态引用与硬编码文本；`/i18n.js` 纳入静态资源白名单与 HTTP 测试。全套 33 项测试通过；浏览器验证了日语刷新记忆、回合 3 语言切换、播放中切换、日语对照表和 390px 英文手机排版。
