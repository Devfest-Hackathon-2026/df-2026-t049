# 前端城市地图与比赛回放

本版使用原创内联 SVG 图形，不依赖第三方素材、API 密钥、额外软件包或收费服务。

## 已实现功能

- 道路绘制和车辆移动共用曲线路径几何，保留真实节点与道路 ID，显示坐标由共享布局模块生成。
- 仓库、避难所建筑及装卸区域，配合需求标签、装饰性街区与树木。
- 两页共用 3 种环境 × 3 套布局，详见 [第四轮地图说明](28-multi-layout-maps.md)。三种明确标注的视觉环境：城市街区、沿河城区、山区城镇。这些是显示环境，不是新增的后端模拟场景。
- 使用 requestAnimationFrame 统一驱动回放，支持保留小数进度的暂停与恢复、倍速调整、整数回合跳转，以及减少动态效果的降级显示。
- 根据真实快照显示封路路障、拥堵示意车列、需求压力符号，以及配送送达和需求增加提示。
- 所有控件和标签支持简体中文、日本語和 English。

## 验证方法

在仓库根目录运行：

```bash
python -m unittest discover -s tests -q
node --check web/app.js
node tests/frontend_replay.cjs
```

前端几何测试使用实际 Python 模拟引擎生成的回放记录，直接调用前端生产代码中的几何函数；覆盖两种 Bot、基础场景、公开事件种子以及三种视觉环境。

## 当前限制

- 车辆位置依据每回合的权威状态快照，不是真实 GPS 数据。
- 信息面板在整数回合边界更新；两帧之间，车辆位置向下一帧进行插值。
- 路口处的车身朝向变化和瞬时卸货仍受到引擎离散回合状态的约束。
- 三种视觉环境保留同一套场景路网；具有明确原因的洪水、地震、滑坡效果需要后端提供可信的事件元数据。

后续接口建议和分工详见[前后端协作需求](frontend-backend-coordination.md)。
