# 每小时 Bot 联赛 — 实施记录

用户已明确授权扩展为持续运行的多人竞技平台。五项要求保持完整：策略或代码 Bot 部署、每小时更复杂场景、自动比赛与公开观战、持久排名、浏览器语言适配。

## 初期实施记录（历史状态）

- `hourly_scenario`：UTC 整点编号决定版本化 seed，6 避难所、5 辆车、48 回合、11 条道路；环形骨架及随机弦边，单条道路封闭后仍可达。仅使用已有封路、拥堵、需求增加事件。
- `League`：SQLite 保存策略 Bot、轮次、成绩和积分；整点前注册的 Bot 参赛，新 Bot 下一小时开始。并发 worker 以事务锁确保同轮仅结算一次，模拟异常整体回滚。
- 积分初始 1000；每轮按同场成对胜负增减，最多 ±16 分；平局零分，单人零分。内部使用千分之一整数，接口展示需除以 1000。这是名次积分，不宣称 Elo 或跨赛季校准。
- 最新轮保留所有完整回放；后续结算清除旧回放，保留成绩摘要、冻结配置及积分变化。停机期间不补跑旧轮，恢复后运行当前小时，避免补跑风暴。
- 第四轮收尾起，首次访问无已保存偏好时默认日本語，不受浏览器语言影响。手动选择 zh/ja/en 优先并同源保存。

本地 worker：`python -m reliefroute.league --db /persistent/league.sqlite3`；`--once` 可运行当前轮并退出。Web 进程配置 `RELIEFROUTE_LEAGUE_DB` 为同一个数据库路径后，`/league` 页面提供参数策略部署、管理、排名和当轮回放。生产 WSGI 未配置时 API 返回 503，不伪造比赛。本地 `python -m reliefroute.server` 现在自动初始化 outputs/local-league.sqlite3（可用 --db 或 RELIEFROUTE_LEAGUE_DB 指定），无需先运行演示脚本；普通启动不结算、不创建 Bot，也不启动 worker。此本地入口忽略云存储 bucket；生产适配器仍须显式配置。

## 第二阶段实现

- 参数 Bot 部署返回随机管理令牌；数据库仅保存令牌 SHA-256，公开列表与回放不包含令牌。暂停和恢复校验令牌，恢复从下一小时起参赛。首版不提供账号找回。
- 注册限制为总计 100 个 Bot；这只是试用容量上限，不是反女巫攻击措施，公开扩展前仍需注册准入及限流。
- API 对 JSON 类型、请求大小、配置枚举和回放参数进行校验。WSGI 与本地 HTTP 共用业务处理。
- 联赛页面用 textContent 渲染用户名称，提供三语内容、自动刷新、全体排名、最新轮比赛与逐回合动态图。历史过期回放返回 404。
- 48 项 Python 测试通过，包括 WSGI 注册、错误令牌拒绝、暂停/恢复、结算及读取真实 48 回合记录。JS 语法检查通过；视觉和浏览器操作验收仍待执行。

## 第三阶段验证与云存储适配

- 本地真实浏览器已完成策略部署、令牌暂停、排行榜查看、48 回合回放到 47/47，以及切换日语后刷新保持。浏览器错误日志为空；使用测试数据库，未改变线上数据。
- 新增 `SnapshotLeague`：配置 `RELIEFROUTE_LEAGUE_BUCKET` 后，从私有 Cloud Storage 对象加载 SQLite 快照，临时文件仅为工作副本；成功写入云端才返回成功。写入携带 generation 条件，冲突时重新加载并重新计算，最多五次。
- 初次创建使用 generation=0；同一轮两个执行者竞争时，失败者重新加载已结算结果，不重复加分。存储失败返回 503，不降级到本机临时存储。
- `python -m reliefroute.league_job` 是一次性私有 Cloud Run Job 入口，使用当前 UTC 小时；没有开放公众结算 HTTP 接口。下一步配置 Cloud Scheduler 调用 Job API。
- 51 项 Python 测试通过，包含模拟 generation 冲突、并发注册不丢数据、并发结算不重复加分、写入失败不声称成功。模拟存储测试不等同于真实 GCS IAM 与网络验证。
- 固定 `google-cloud-storage==3.17.1`，已核实注册表存在。此快照方案适合小规模试用，每次请求会读取数据库；不是高吞吐存储设计。需要进一步进行容量与超时测量。
- 官方依据：[Cloud Storage generation preconditions](https://docs.cloud.google.com/python/docs/reference/storage/latest/generation_metageneration)。
